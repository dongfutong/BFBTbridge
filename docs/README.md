# BFBTbridge docs

This repository is **distribution-only** (installers + screenshots + this index). Canonical product documentation lives on the DTrony website. Do not treat this folder as a second source of truth.

**BFBTbridge** is the PC-resident **AI agent bridge** / **multi-agent connector** / **coding agent scheduler** for local coding agents (Cursor, Codex, [BFBT Code](https://github.com/dongfutong/BFBTCode)). Pair with [DTworkeasy](https://github.com/dongfutong/DTworkeasy-Mobile) via QR code.

Installers and screenshots: [repository README](../README.md).

## Trial / membership

Kept here because the product docs mention pricing:

- **BFBTbridge** and **BFBT Code** share the same rule: an active trial or paid membership is required.
- One membership covers **both** BFBT Code and BFBTbridge.
- **DTworkeasy** (mobile) stays free after registration.
- BFBTbridge does not sell model tokens; usage of Cursor / Codex / BFBT Code follows each agent’s own account.

Source: [会员权益](https://www.dtrony.com/docs/membership-benefits).
